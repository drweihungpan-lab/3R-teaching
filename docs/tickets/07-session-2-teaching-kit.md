## What to build

The instructor can teach Session 2 and students can trace the working healthcare processing package, install it in editable mode, and make a small maintainable change through their group workflow.

## Acceptance criteria

- [ ] Provide editable English PowerPoint slides, matching Markdown sources, instructor notes, and guided practice with expected observations.
- [ ] Explain modular functions, separation of processing/API/UI responsibilities, package metadata, dependencies, editable installation, type hints, and logging.
- [ ] Use the actual supplied healthcare processing example and make a bounded processing or logging change; do not require students to refactor an entire application.
- [ ] Include approximately two hours of mandatory homework applying a small documented change relevant to the group's chosen data question.
- [ ] Reinforce meaningful PR review and keep the provisional three-hour session allocation.
- [ ] Provide an explanation or reference solution for the exercise without shipping an intentionally incomplete default template.
- [ ] Keep model complexity and unnecessary class abstractions outside the core learning objective.
