## What to build

Prepare the implemented framework for group repository creation and author the Git/review guidance used during the course.

## Acceptance criteria

- [ ] Provide instructor steps for enabling GitHub template use and instructions for creating a group's own repository.
- [ ] Provide PR guidance for change purpose, local tests, CI evidence, and meaningful peer review.
- [ ] Document feature branches, descriptive commits, reviewed PRs, and merges into main without a develop branch.
- [ ] Document required-check/branch-protection setup for each generated repository without claiming those settings are inherited.
- [ ] Explain how the instructor can inspect each student's authored PR and review of a teammate's PR.
- [ ] Keep the example working and provide setup guidance rather than requiring actual student repositories or student participation to close this task.
