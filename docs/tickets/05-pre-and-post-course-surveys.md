# Draft 05: Provide paired pre-course and post-course surveys

Publication status: proposed; awaiting approval of the breakdown. Draft numbers are not GitHub issue numbers.

## Parent

https://github.com/drweihungpan-lab/3R-teaching/issues/1

## What to build

The instructor can assess prior experience and setup readiness before class, then compare matched questions about confidence and understanding after the course and collect feedback.

## Acceptance criteria

- [ ] Provide plain-English, ready-to-use survey text with a short purpose statement.
- [ ] Cover Python, Git/PR review, virtual environments, packaging, APIs, tests/CI, containers, and the course definitions of the three Rs at an appropriate introductory level.
- [ ] Include pre-course readiness questions for tools and account access, without asking for credentials or introducing unagreed prerequisites.
- [ ] Repeat relevant questions with the same response scales before and after the course so answers can be compared.
- [ ] Include post-course questions about workload, pacing, useful activities, and improvements.
- [ ] State that surveys support course evaluation and do not contribute to pass/fail assessment.
- [ ] Do not require a hosted survey service, automated data collection, or a new analytics application.
