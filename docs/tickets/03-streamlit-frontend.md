## What to build

## Acceptance criteria

- [ ] Accept participant and laboratory CSV uploads and call the documented FastAPI contract.
- [ ] Display cleaned results, observed/missing counts, summaries, and one simple chart.
- [ ] Make backend address configurable for local and later container use.
- [ ] Show useful messages for rejected input, connection failures, and timeouts.
- [ ] Document local startup and a manual demonstration using the sample data.
- [ ] Keep interface design simple and complete; do not require students to build or finish the UI.
