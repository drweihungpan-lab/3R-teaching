## Acceptance criteria

- [ ] Provide executable steps to follow an API request, inspect validation, introduce a controlled test failure, correct it, and inspect local and remote checks.
- [ ] State prerequisites, expected observations, and a clear stopping point suitable for approximately 90 minutes of guided practice.
- [ ] Make activities small modifications or inspections of working code, not construction from scratch or unfinished-function assignments.
- [ ] Include expected outputs and a recovery/reference explanation for the instructor.
- [ ] Use the actual implementation's commands and behavior and state any unverified steps.
- [ ] Keep homework, slide production, and instructor run-sheet authoring in their separate tasks.
